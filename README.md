# ☕ Coffee Loyalty Bot - Бонусная система для кофейни

![Python](https://img.shields.io/badge/Python-3.9+-blue.svg)
![Aiogram](https://img.shields.io/badge/Aiogram-3.x-green.svg)
![License](https://img.shields.io/badge/License-MIT-yellow.svg)

Telegram-бот для управления программой лояльности кофейни с тремя ролями пользователей: клиенты, администраторы и SMM-менеджеры.

## 🌟 Возможности

### 👨‍💻 Для клиентов
- 📱 Простая регистрация по номеру телефона
- 📲 Персональный QR-код для идентификации
- 💰 Просмотр бонусного баланса
- 📊 История всех операций
- 📢 Получение новостей и акций

### 👔 Для администраторов
- 🔍 Сканирование QR-кодов клиентов
- ⌨️ Ручной ввод ID клиента
- ➕ Начисление бонусов (5-7% от суммы чека)
- ➖ Списание бонусов
- 📈 Просмотр статистики клиента

### 📢 Для SMM-менеджеров
- ✍️ Создание новостных постов (текст + изображение)
- ✏️ Редактирование существующих публикаций
- 🗑️ Удаление постов
- 📣 Массовая рассылка новостей клиентам

## 🛠 Технологии

- **Python 3.9+** - основной язык
- **Aiogram 3.x** - фреймворк для Telegram ботов
- **SQLite3** - база данных
- **QRCode** - генерация QR-кодов
- **PyZBar** - декодирование QR-кодов

## ⚙️ Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/yourusername/coffee-loyalty-bot.git
cd coffee-loyalty-bot
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Настройте окружение:
```bash
cp .env.example .env
```
Отредактируйте `.env` файл:
```ini
BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_IDS=123456789,987654321  # ID администраторов через запятую
SMM_IDS=112233445,556677889    # ID SMM-менеджеров через запятую
```

4. Запустите бота:
```bash
python3 main.py
```

## 📊 База данных

Бот автоматически создает SQLite базу данных с таблицами:

1. **users** - информация о пользователях
   - user_id, username, full_name, phone, bonus_points

2. **transactions** - история операций
   - id, user_id, amount, description, timestamp

3. **news** - новости и акции
   - id, author_id, title, content, image_path, timestamp

## 📜 Логирование

Бот ведет подробные логи в файл `coffee_bot.log` и выводит их в консоль:
```
2023-12-01 12:00:00 - root - INFO - Bot started successfully
2023-12-01 12:01:23 - handlers - INFO - User 123456 registered
```
