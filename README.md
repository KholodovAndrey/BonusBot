Coffee Bonus Bot ☕🤖
Описание проекта
Telegram-бот для автоматизации бонусной программы кофейни. Позволяет клиентам участвовать в программе лояльности, а администраторам - легко управлять бонусными счетами.

Основные функции
Для клиентов:
✅ Простая регистрация в системе (/register)

🏷 Персональный QR-код бонусной карты

💰 Проверка баланса бонусных баллов

📊 Просмотр истории операций

🛒 Использование баллов для получения скидок

Для администраторов:
📲 Сканирование QR-кодов клиентов (через фото)

➕ Начисление бонусных баллов

➖ Списание баллов

🔍 Поиск клиентов по ID

📊 Анализ активности клиентов

Технологический стек
Python 3.10+ - основной язык разработки

Aiogram 3.x - фреймворк для Telegram ботов

SQLite - база данных для хранения информации

QRCode - генерация персональных QR-кодов

PyZBar - декодирование QR-кодов из изображений

Pillow - работа с изображениями

Pydantic - валидация данных

Установка и запуск
Требования:
Python 3.10 или новее

Аккаунт Telegram

Токен бота от @BotFather

Пошаговая установка:
Клонируйте репозиторий:

bash
git clone https://github.com/ваш-репозиторий/coffee-bonus-bot.git
cd coffee-bonus-bot
Создайте и активируйте виртуальное окружение:

bash
python -m venv venv
source venv/bin/activate  # Linux/MacOS
venv\Scripts\activate    # Windows
Установите зависимости:

bash
pip install -r requirements.txt
Настройте конфигурацию:

bash
cp .env.example .env
Отредактируйте файл .env, добавив ваш токен бота:

text
BOT_TOKEN=ваш_токен_бота
Запустите бота:

bash
python main.py
Настройка администраторов
Добавьте ID администраторов в файле main.py:

python
ADMIN_IDS = [123456789, 987654321]  # Замените на реальные ID администраторов
Руководство пользователя
Для клиентов:
Начните с команды /start

Зарегистрируйтесь командой /register

Используйте /menu для доступа к функциям:

"Мой QR-код" - ваша бонусная карта

"Мои бонусы" - текущий баланс

"История операций" - последние транзакции

Для администраторов:
Введите команду /admin

Выберите действие:

"Сканировать QR" - отсканируйте QR-код клиента

"Начислить бонусы" - добавьте баллы

"Списать бонусы" - уменьшите баланс

"Отмена" - выйдите из текущего действия
